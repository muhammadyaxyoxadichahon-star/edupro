# EduPro Android

EduPro — Kotlin va Jetpack Compose asosidagi ta'lim ilovasi.

## Talablar
- Android Studio
- JDK 17
- Android SDK 35

## Ishga tushirish
1. Repository'ni Android Studio orqali oching.
2. Gradle Sync tugashini kuting.
3. Emulator yoki Android qurilmada Run bosing.

- 5–11-sinflarni tanlash
- Fanlar ro'yxati
- Mavzular va bajarilgan mavzular hisoblagichi
- Test uchun boshlang'ich sahifa
- Profil va o'quv statistikasi
